ServePlus – Food Delivery App UI/UX Design

A food delivery app designed in Figma during my UI/UX internship at Media Wave Technology, Tiruchirappalli (June–July 2026).

About

ServePlus is a food delivery app UI/UX design project focused on making food ordering simple, clear, and convenient. The design helps users browse restaurants, select food, place orders, and track deliveries through an easy-to-follow user flow.

Screens

The project includes the following screens:

- Splash Screen
- Login
- Sign Up
- Home
- Restaurant Menu
- Cart
- Checkout
- Order Confirmed
- Track Order
- Order Delivered

1. Studied existing food delivery applications.
2. Identified common usability issues.
3. Planned the user flow.
4. Created wireframes.
5. Selected colours, typography, and reusable UI components.
6. Designed the screens in Figma.
7. Connected the screens to create a clickable prototype.
